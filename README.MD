# Python Study 项目

这是一个Python学习项目，包含多个练习脚本和示例代码。

## 📁 项目结构

- **abc=28.py** - 数学算法练习
  - 找出三个不同数字，其和为28，并计算最大和最小的乘积
  - 包含回文数判断函数

- **testforgg01.py** - 闰年判断程序
  - 实现闰年判断逻辑
  - 闰年规则：能被4整除但不能被100整除，或者能被400整除
  - 包含多个测试用例

- **爬取天气.py** - 网页爬虫示例
  - 使用 BeautifulSoup 爬取天气信息
  - 演示HTTP请求和HTML解析
  - 从天气网站获取城市天气数据（日期、天气、温度、风力等）

- **zbc001.prog.abap** - ABAP程序代码

## 🛠️ 技术栈

- Python 3.x
- 库依赖：
  - `requests` - HTTP请求库
  - `beautifulsoup4` - HTML/XML解析库

## 📦 安装依赖

```bash
pip install requests beautifulsoup4
```

## 🚀 使用方法

### 运行abc=28.py
```bash
python abc=28.py
```

### 运行testforgg01.py
```bash
python testforgg01.py
```

### 运行爬取天气.py
```bash
python 爬取天气.py
```
